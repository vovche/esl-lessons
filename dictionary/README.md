# Словник вимови

Це спільний статичний сервіс для навчальних сторінок репозиторію. [Сторінка словника](index.html) читає `words.json` і відтворює MP3-файли з репозиторію без запиту до зовнішнього сервісу вимови.

В уроках англійські слова, що є в словнику, позначені крапковим підкресленням. Тап або Enter відкриває картку поверх уроку, без втрати поточної вправи. Короткий `word-index.json` завантажується разом з уроком; повний `words.json` потрібен лише після першого відкриття картки. Якщо JavaScript недоступний, посилання веде на пошук цього слова у словнику. Текст усередині кнопок та інших керувальних елементів не перетворюється на посилання, щоб не змінювати їхню дію.

## Що входить

- Слова з видимого тексту уроків 6, 7 і 9 класів, включно з формулюваннями вправ і текстовими фрагментами запитань у JavaScript.
- Слова з карток Jolly Phonics (`6/jolly-phonics/data/cards.json`).
- Форми слова збережено окремо: `do`, `does`, `doing` мають окремі записи. Імена учасників історій також збережено, якщо вони видимі учням.

Інвентар не включає назви CSS-класів, JavaScript-ідентифікатори, розширення файлів, окремі літери, що позначають звуки, та навмисно неправильні написання в дистракторах вправ. Це словник **навчального англійського тексту**, а не програмного коду.

## Дані запису

Кожен запис містить:

- IPA для британської та американської вимови;
- наближений запис звуків українськими літерами для обох акцентів;
- коротку фонікс-підказку англійською;
- чотири MP3: британський чоловічий і жіночий, американський чоловічий і жіночий голоси;
- посилання на уроки, у яких слово трапляється.

IPA генерується з [eSpeak NG](https://github.com/espeak-ng/espeak-ng). Чотири записи вимови створені нейронними голосами через [edge-tts](https://github.com/rany2/edge-tts): британські Sonia та Ryan, американські Jenny та Guy. Аудіо зберігається в репозиторії як MP3, тому під час відтворення зовнішній TTS-сервіс не потрібен. Український запис і фонікс-підказки створює локальний алгоритм; для неоднозначних слів, наприклад `read` або `present`, показано вимову окремого слова, яку обрав синтезатор. Український запис не є фонетичною нормою й має допоміжну роль. Аудіо синтетичне, записане у файли, а не згенероване браузером під час перегляду. Кожна картка також має посилання на пошук `слово pronunciation` у Google для додаткового прослуховування.

## Оновлення

На машині з `libespeak-ng.so.1`, `ffmpeg` і Python 3.11+ встановіть залежність із [`scripts/requirements-dictionary-audio.txt`](../scripts/requirements-dictionary-audio.txt), а потім:

```bash
python3 scripts/build_dictionary.py --no-audio
python3 scripts/generate_dictionary_neural_audio.py
python3 scripts/build_dictionary.py --check
```

Перша команда оновлює інвентар і транскрипції. Друга запитує нейронні голоси пакетами, нарізає їх за часовими мітками слів і записує відсутні MP3. Справні готові записи повторно не завантажуються. Після зміни уроку запуск перевірки в GitHub Actions виявить нові слова, яких немає в словнику. Точну вимову слів з кількома значеннями можна надалі редагувати вручну в джерелі даних або вдосконалити генератор.
