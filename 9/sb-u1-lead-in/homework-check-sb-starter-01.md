## 4. 2 бали

Для чого в уроці радять слухати запис двічі?

1. Обидва рази лише рахувати слова.
2. Спочатку для головної думки, потім для деталей.
3. Лише для перевірки гучності.
4. Щоб уникнути будь-яких запитань.

## 5. 2 бали

Прочитай: Emma plans to practise regularly, ask questions and keep a record of useful phrases. Яка дія відповідає її плану?

1. Виписувати корисні фрази й регулярно їх повторювати.
2. Ніколи не ставити запитань.
3. Зберігати лише список цін.
4. Читати лише раз на рік.

## 6. 3 бали

Учень хоче поліпшити розуміння англійської. Який план поєднує конкретну дію, повторення і роботу над помилками?

1. Я стану ідеальним без практики.
2. Я послухаю один запис і ніколи до нього не повернуся.
3. Щодня слухатиму короткий запис: спочатку для змісту, потім для деталей; виписуватиму фрази й виправлятиму помилки.
4. Я лише порівнюватиму себе з іншими.
