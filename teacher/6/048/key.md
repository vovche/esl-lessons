# Ключ учителя · урок 048

Не долучати цей аркуш до учнівської роздатки.

## Блок 1: Outer space

1. **C — the largest**. Large → the largest.

2. **B — hottest**. Найвищий ступінь hot → hottest.

3. **A — the most**. Для довгого прикметника: the most interesting.

4. **C — Eight.**. У першому реченні названо eight planets.

5. **B — The biggest.**. Для всієї групи використовується найвищий ступінь.

Вправа 5, можливий тематичний діалог: A: Which planet is the largest in this imaginary group? B: Planet C is the largest. A: Is planet A hotter than B? B: No, it is colder.

Вправа 4, можливий варіант: Два факти: Our solar system contains the sun and eight planets. Planets differ in size, temperature and distance from the sun. Мій вигаданий варіант: Fictional data: A — size 3, temperature 10, distance 5; B — size 5, temperature 20, distance 8; C — size 8, temperature 30, distance 12 (arbitrary units). C is the largest.

## Рубрика відкритого продукту

Робоча аналітична рубрика, не офіційне переведення в 12 балів. За кожним критерієм: 0 — доказу ознаки немає у наданій роботі; 1 — частково; 2 — достатньо для сформульованого завдання. Критерії: (1) виконання змістового завдання; (2) зрозумілість і зв’язність; (3) доречні слова / форми. Для S додатково описово зафіксувати реакцію на партнера та зрозумілість усного мовлення; підказки / читання заготовки відмічати. Для W позначити самостійну правку. Сума 0–6 — лише внутрішня опора для зворотного зв’язку. Відсутність доступу позначати «немає доказу», не нулем. Дозволені інші змістовні відповіді, вигадані персонажі й альтернативні рішення. Приклад зворотного зв’язку: «Ти назвав місце й час; наступний крок — додати причину з because».
