# Перевірка опублікованих місій 6 класу без мережі

Перевірено 18.10.2026 близько 23:14 за Києвом у справжньому Playwright Chromium 151.0.7922.34. Для кожного проходження створено свіжий браузерний контекст без попереднього кешу й прогресу; розміри 390×844 і 320×844, мобільний viewport із touch. Сертифікати HTTPS не ігнорувалися; локальна копія сайту та локальний JSON не використовувалися. Запити до сторонніх ресурсів не підмінялися.

Цільова сторінка: https://vovche.github.io/esl-lessons/6/sb-hello/ . В обох режимах перевірено другу календарну ситуацію `g6-002` («Сімейний календар героїв»), щоб відрізнити відновлення вибору від показу першого пункту за замовчуванням.

Публічні дані отримано безпосередньо з https://vovche.github.io/esl-lessons/6/simulations.json ; HTTP 200. SHA-256 отриманого UTF-8 тексту: `322ebf1a589a3aee2dbe714c8d5406cff52c9e2d917c5f38f7d134ef99429e75`. Правильні/неправильні тестові переходи вибиралися з цього опублікованого JSON, а не з локальних учительських ключів.

У кеші `esl-missions-v1` кожного контексту було рівно шість URL під справжнім префіксом GitHub Pages: `offline-simulations.html`, `assets/offline-simulations.js`, `assets/lesson-simulations.js`, `assets/lesson-simulations.css`, `assets/lesson-theme.css`, `6/simulations.json`. Вчительських файлів, відео та Jolly Phonics серед них немає. Оболонка прямо пояснює, що повний урок і відео потребують мережі.

## Візуальні докази й межі

Тимчасові локальні докази: `/tmp/grade6-published-offline/results.json` і PNG `loaded-offline-pause.png`, `offline-reload-shell.png`, `offline-score-draft.png`, `cold-offline.png`; окремий прохід на 320 px — відповідні файли в `/tmp/grade6-published-offline-320/`. Візуально прочитано оболонку після reload, поле відновленої чернетки з кнопками та порожній екран холодного offline-візиту на 390 px, а також підсумкову чернетку на 320 px. Текст переноситься в межах екрана, кнопки не перекривають завдання. Файли `/tmp` не є постійними вкладеннями репозиторію.

Це перевірка однієї опублікованої сторінки з двома режимами однієї непершої ситуації, а не всіх 246 ігор. Вона підтверджує реальний HTTPS/service-worker шлях GitHub Pages, але не роботу фізичних мобільних пристроїв, Safari/Firefox, вивантаження кешу ОС, очищення сховища чи приватного режиму. Збереження прогресу перевірено в межах одного браузерного контексту між reload та новими вкладками; довготривале зберігання після перезапуску ОС не моделювалося.
