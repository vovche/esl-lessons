# Ігрові симуляції · 6 клас · урок 024

Планова дата: 2026-10-16. Тема: Подорожі колись і тепер — мовні структури й мовленнєва практика. Мовний матеріал: Travelling then and now; фокус: used to.

Обрати одну гру замість звичайної практики: гра1 займає 20–28 A (або 16–24 C); гра2 займає 37–42 A (або 36–41 C). Якщо обрано гру1 на продуктивному уроці, її короткий продукт замінює відповідну частину вправи4; не вимагати додаткового повного твору. Разом із заміненим блоком загальна тривалість залишається45хв. Обидві гри одночасно не обов’язкові.

Спільна доступність: усі ролі й дані вигадані. Камера необов’язкова. У команді A приймає рішення, B перевіряє джерело, потім ролі міняються; соло учень веде обидві ролі на папері. У чаті пишуть «хід1 + відповідь», учитель відповідає станом; це письмова взаємодія. В укритті — тільки за дозволу після переміщення й прийнятних умов, мовчки: обвести вибір, провести стрілку до наступного стану. Можна пропустити гру або грати без рейтингу. За відсутності умов — пауза; під час переміщення завдань немає. Усний доказ — тільки фактично почута репліка у придатних умовах; чат / папір не зараховуються як говоріння. Для контрольних L паперова гра тренує читання / мовний матеріал; аудіювання перевіряють окремо зі звуком.

## 1. Засвоєння, 7 хв — Музей транспорту

Роль: куратор порівняльної виставки. Мета: Підпиши транспорт колись і тепер через used to / didn’t use to.

Стартовий стан: два експонати без часових ярликів; два рішення ще не прийнято, стан0/2. Ресурси на папері нижче: текст, дві картки й модель. Учитель: “You can use the model. Choose, check and try again.”

Модель: People used to travel on slow ships. Did they use to spend months at sea? Trains did not use to be so fast.

Матеріал стану (можна читати й підкреслювати): Travel has changed. Explorers used to spend months at sea before they saw land. Early trains were much slower than many trains today. Travelling by plane used to be difficult, but now people can cross long distances quickly. Electric cars are another way to travel, and drivers need places to charge them.

Картка ходу1:

“People ___ travel on slow ships.”

A) use to / B) are used / C) used to

Картка ходу2:

“Did trains ___ be so fast?”

A) using to / B) use to / C) used to

00–01: учень бере роль і читає ціль. 01–03: обирає варіант ходу1 й каже / пише “I choose…” + потрібну форму або відповідь. Правильне рішення → стан1/2, перша картка прийнята. Інше рішення → картка повертається на виправлення, стан0/2; жодної втрати оцінки.

03–05: учень робить хід2; партнер питає “Why this one?” Потрібен один змістовий доказ або посилання на правило. Правильне рішення → стан2/2. 05–07: учень змінює одну деталь мовної моделі (герой, предмет, час у дозволеній структурі) та перевіряє, чи не змінився сенс форми. Стан успіху: відвідувач бачить відмінність then / now; одна власна тематична зміна зрозуміла.

Відповіді для вчителя: хід1 — C — “used to”. Підстава: Минула звичка: used to + travel. Хід2 — B — “use to”. Підстава: Після did форма use to. Допустимий приклад зі зміненою деталлю: People used to travel on slow trains.; інші приклади прийнятні, якщо зберігають цільову структуру й тематичний сенс.

Помилка → підказка → повтор: учитель не називає літеру; пропонує “Check the model” і вказує потрібну форму / факт. Учень змінює рішення й пояснює одну причину. Спостережуваний доказ засвоєння: два виправлені рішення та одна власна зміна. Позначити, що опора була доступна; не подавати це як незалежну контрольну спробу.

## 2. Перевірка, 5 хв — Нова ситуація «Travelling then and now»

Роль: незалежний перевіряльник двох нових заявок за ракурсом «Travelling then and now» цієї календарної теми. Старт: у черзі дві заявки, статус «не перевірено». Ціль — прийняти тільки обґрунтовані мовні / змістові рішення й виправити одну неточність до відправлення. Модель та ключ на першій спробі закриті.

Окремий паралельний контекст для перевірки (це не вправа3 аркуша; мовні форми пояснюють правилом):

In this imaginary town, people used to walk to the island. Now they use a bridge.

Заявка1:

“People ___ walk to the island.”

A) used to / B) use to yesterday / C) using to

Заявка2:

“Did they ___ use a bridge?”

A) used to / B) using to / C) use to

00–01: учень читає дві заявки. Обирає дію «check first» або «send now»; без обґрунтування одразу відправлена заявка повертається як «потрібен доказ», її не зараховують як правильний мовний результат. 01–03: перевіряє заявку1, обирає мовний варіант і додає факт / правило: “My evidence is…”; за правильного рішення статус «готово1/2». 03–04: перевіряє заявку2, записує відповідь і доказ, статус «готово2/2». 04–05: показує / надсилає обидва рішення. Стан успіху — два змістовно правильні самостійні рішення з доречним доказом; жодного заліку за сам факт кліку / відправлення.

Ключ для вчителя (учням не показувати до першої спроби): заявка1 — A — “used to”. Підстава: Паралельний контекст: In this imaginary town, people used to walk to the island. Now they use a bridge. Правильний вибір: used to Заявка2 — C — “use to”. Підстава: Паралельний контекст: In this imaginary town, people used to walk to the island. Now they use a bridge. Правильний вибір: use to Робочий запис: «2/2 самостійно», «1/2 самостійно» або «потрібен наступний приклад»; це формувальна перевірка двох ознак, не повний висновок про урок і не офіційна оцінка.

Якщо помилка: спочатку зберегти першу відповідь як самостійний доказ. Тільки потім відкрити відповідний рядок тексту / модель; учень повторює хід іншою позначкою. Успіх після підказки записують окремо «із підтримкою», не переписують первинний результат. Спостережуваний мовний доказ: конкретні відповіді до двох заявок плюс дві підстави; у чаті це письмовий доказ. Для сильнішого учня замість вибору — закрити варіанти й сформулювати відповідь самостійно у тому самому часі.
