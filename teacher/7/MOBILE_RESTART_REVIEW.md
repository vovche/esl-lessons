# Мобільна емуляція: закриття процесу й офлайн-запуск · 7 клас

**Фінальний результат: Chromium PASS, WebKit PASS** через мережевий HTTP CONNECT-проксі. Перевірено опублікований HTTPS-сайт2026-10-18. В обох рушіях037learn і065check відновилися після двох повних закриттів та повторних запусків без доступу до мережі. Це **мобільна емуляція на Linux**, не фактичні AndroidChrome або Safari/iPhone.

## Метод і адреси

- [Фуд-арт, друга ситуація037learn](https://vovche.github.io/esl-lessons/7/sb-u3-reading/).
- [Самоперевірка, шоста ситуація065check](https://vovche.github.io/esl-lessons/7/sb-u1-self-check/).
- JSON та effect-ключі отримано тільки з [опублікованого JSON](https://vovche.github.io/esl-lessons/7/simulations.json) під час першого онлайн-запуску. SHA256: `0d4353f9132960590cfaee67eff807ac56c9f0b7ed3ed802dbe3e47fb6d9d35d`.
- `launchPersistentContext` використовує той самий userDataDir для трьох послідовних процесів; для іншого рушія — окремий свіжий профіль. `await context.close()` закриває браузер повністю; перевірено `browser.isConnected() === false`. Перед закриттям також закривали сторінки, щоб відновлення вкладок не підміняло нову навігацію.
- Viewport390×844, mobile/touch emulation, reduced motion. Рішення, меню, пауза й підказка — `tap()`, вибір ситуації — `selectOption`, чернетка — `fill`.
- **Фінальний мережевий спосіб:** Playwright `offline:false` залишається незмінним. До офлайн-запуску проксі переводиться в blocked-стан: усі чинні сокети/CONNECT-тунелі знищуються, нові відхиляються. Додатковий uncached fetch `simulations-sw.js?restart-probe=...` підтверджує недоступність мережі. Онлайн-прогріву після повторного запуску перед цією перевіркою немає.
- Зовнішні origins блокувалися для відокремлення сторонніх iframe. Повний урок, відео та довільні зовнішні ресурси не заявляються доступними офлайн.

1. Онлайн підготовлено обидві адреси й дочекалися явного підтвердження офлайн-готовності. У037 зроблено хибний перший вибір, відкрито підказку й поставлено на паузу. У065 зафіксовано хибний перший вибір самостійного режиму.
2. Повністю закрито браузер. Той самий профіль запущено повторно з уже заблокованим транспортом. Відкриваються ігрові оболонки, автоматично відновлюються саме037/065. Uncached запити не проходять.
3. У037 повернулися пауза, відкрита підказка та перша помилка. У065 обидві кнопки прийнятого ходу залишилися заблокованими, підказки до завершення немає. Після завершення обидві місії показують **1/2**: відновлення не переписало перший хибний вибір.
4. Записано `Restart draft 37 chromium.` / `Restart draft 65 chromium.` або відповідні рядки з `webkit`, без окремої кнопки збереження. Повністю закрито браузер удруге.
5. Третій процес з тим самим профілем запускається при заблокованому транспорті. Відновлено правильну ситуацію кожної адреси, завершений результат1/2 і точні чернетки.
6. Явна перевірка зв’язку офлайн показує читабельне пояснення й залишає гру відкритою з цілою чернеткою. Після розблокування проксі й натискання повернення завантажується **повний урок**; ситуація, результат і чернетка збережені.

## Знайдений UI-ready race

Початкове швидке натискання одразу після `DOMContentLoaded` офлайн-оболонки не відкрило місії: розділ уже показував кнопку, але асинхронний runtime ще не встановив listener. `/tmp/g7-restart-chromium-failure.png` показує незмінений напис «Відкрити місії» без fetch-помилки. Координатор підтвердив порядок у bootstrap-коді й виправив блокування кнопки до готовності runtime; окремо повідомив PASS delayed-runtime regression у Chromium і WebKit.

Фінальний grade7 цикл перевіряв **збереження** з явним очікуванням змонтованого runtime перед натисканням. Це не приховує початкового race й не видається за окреме підтвердження його майбутнього production-деплою.

## Чому попередній WebKit-прогін був невдалим

Перший запуск не відбувся через відсутню `libevent-2.1.so.7` (exit127); координатор відновив залежність. Це помилка тестового середовища, не сайту.

Далі варіант із Playwright `offline:true` після закриття процесу давав `WebKit encountered an internal error` на першій навігації до обох адрес037/065. Гра не відкривалася; screenshot був порожнім. Окремий онлайн-запуск того самого профілю `/tmp/g7-restart-webkit-doGDLs` довів, що localStorage збережений: у037 `first:[false,null]`, `hint:true`, `paused:true`; у065 `phase:accepted`, `first:[false,null]`. CacheStorage та service-worker registration теж залишилися. Діагностика `/tmp/g7-webkit-restart-diagnostic.json`.

Після заміни прапорця емуляції на фактичне блокування CONNECT-транспорту повний цикл WebKit пройшов. Отже, попередній збій **не є доказом втрати даних чи несправності сайту на Safari**; це окремий результат конфігурації WebKit+Playwright offline-flag. Початкові протоколи `/tmp/g7-mobile-restart-{chromium,webkit}-results.json` збережено окремо від фінальних proxy-результатів.

## Межі

Фізичні телефони, справжній Safari/iOS, системне примусове завершення посеред запису, очищення даних, приватний режим і заблоковане сховище не перевірялися. Закриття штатне, після запису. Фінальний проксі відключає весь мережевий доступ цього браузера; це не перевірка апаратного авіарежиму. Мовні ключі повторно не переаудитовано: оцінюється відновлення стану за опублікованими даними. Shared-код, JSON і PDF цього потоку не змінювалися; додано тільки цей приватний звіт.
