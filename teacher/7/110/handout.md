Усі життєві ситуації можна вигадати. Камера добровільна. Особисті історії не потрібні. За небезпечних умов припини завдання; у русі до укриття не вчимося.

**Сьогодні обов’язково:** G: 4 вибори; T: 2 перетворення. Резерв учитель дає лише замість завершеного блоку. Не потрібно виконувати всі вправи з конспекту.

## Опора · 4 робочі слова

performance — вистава; stage — сцена; audience — глядачі; comedy — комедія.

Складні слова з авторської картки можна уточнити в учителя; це не новий обов’язковий словниковий диктант.

## Модель

Порівнюємо ознаки: more/less + довгий прикметник + than; as + прикметник + as; the same as. Для коротких прикметників — -er.

The first half is more interesting than the second. This play is not as long as that film. The ending is less predictable.

## G · Обери форму

1. This film is more interesting ___ that one. (than / as) → __________
2. This play is as long ___ that film. (than / as) → __________
3. The plot is ___ predictable than the ending. (less / as) → __________
4. These two tickets cost the same ___ those tickets. (as / than) → __________
