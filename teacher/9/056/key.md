# Ключ і критерії ·9 клас · урок 056

Тільки вчителю. Не друкувати з учнівською роздаткою. Фокус: **обмежена діагностика / контроль: види перевіряються окремо**.

## Закриті цільові відповіді

1. **A — twenty minutes**. Текст прямо вказує twenty minutes.

2. **C — one clear example**. Each station needs one clear example.

3. **B — the accuracy of information**. Check that its information is accurate.

4. **A — is organised**. Регулярна подія: is + V3.

5. **C — liked**. У заданому минулому контексті: like → liked.


## Повний модельний продукт саме потрібного жанру

Our display links club teamwork with checking media sources. Each station should show one clear example. This will help visitors understand the main point without reading a long list. We have twenty minutes for a draft, so I suggest choosing useful information first and checking its accuracy before sharing the display.

Це один прийнятний варіант, не єдиний. Оцінювати відповідність точному prompt: Write a short display note (45–65 words): choose two different stations, give one accurate contextual example for each, and explain one useful decision. No requirement to cover every station in a long essay.

**Критерії 0–6:** зміст/необхідні частини жанру 0–2; точність цільових форм/фактів 0–2; зрозумілість і логічність 0–2.0 — доказу немає;1 — частково або зі змістовою неточністю;2 — достатньо й зрозуміло. Для chart оцінюються рядки, для CV — рубрики та доказ навички, для survey — правильні чисельності/відсотки й межі узагальнення, для e-mail — адресат/повідомлення/закінчення. Не вимагати однакових двох причин і поради у всіх жанрах. Нецiльова помилка не штрафується вдруге за той самий зміст.

Для відкритого пояснення закритого пункту: приймати змістовно еквівалентну аргументацію українською або англійською. Для читання достатній точний переказ фрази-доказу. Закриті пункти: по 1 за правильну відповідь, пояснення фіксується як окремий формувальний доказ. Показ ключа/рамки з готовою відповіддю до спроби позначається як робота з опорою.

## Мінімум B/D

Конкретний ключ / прийнятна модель: A fictional school team is preparing a display. Question: What other detail would help us decide? Відкриті інші відповіді приймаються, якщо відповідають саме короткому завданню цієї дати й зберігають цільове значення/форму. Це тренувальний мінімум, не завершений контроль. Одна репліка/поле не отримує оцінку за весь жанр.

## Текст слухання — тільки вчителю до завершення

A different team is preparing a display for the next lesson. It has fifteen minutes for its first draft. Before sharing, the team will check the spelling and dates. Robin will ask another editor to read the draft.

Прочитати двічі з 20–30 с паузою в межах 08–16; повтор не супроводжувати transcript. Після завершення можна дати текст для аналізу помилок.

Слухання:1) fifteen minutes;2) the spelling and dates. По 1 балу. Це 2 факти короткого повідомлення, не доказ повного рівня слухання семестру.

## SEL-рефлексія не оцінюється

Запитання про стратегію й перенос не має єдиної правильної відповіді. Не включати його у 0–6,мовніMCQчи підсумковийбал. Пауза/мовчазнероздумування/пропуск не знижують результат.

## Реальний облік

Усні 5 хв — максимум 2–3 індивідуальні проби. Для решти індивідуальні слоти/асинхронний запис за доступності з оголошеною процедурою, інакше «не перевірено». Самодіалог/читання моделі не доводять спонтанної взаємодії. Сирі результати — профіль умінь, не автоматичний 12-бальний підсумок. На 117 письмових резервних MCQ немає; окремо збираються слухові та усні докази. Короткі контрольні зразки не підміняють обов’язковий повний обсяг програми.
