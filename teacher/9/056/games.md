# Ігрові симуляції ·9 клас · урок 056

**Точний фокус:** обмежена діагностика / контроль: види перевіряються окремо. Teacher-only: тут є ключі. Усі персонажі/навчальні ситуації вигадані, якщо історичне джерело не зазначене окремо.

## 1. Майстерня рішення — засвоєння,8 хв

**Замість 16–24 A/C**, а не додаткові 8 хв. При підсумковому контролі цю гру використовують як окреме попереднє тренування, не всередині самостійного доказу. Ролі: редактор і консультант; соло — той самий учень спершу редактор, потім читає пояснення. Початковий стан: чернетка 0/2, дозвіл на використання ще не отримано. Мета — ухвалити два предметні рішення саме цієї дати й підготувати фрагмент «обмежена діагностика / контроль: види перевіряються окремо».

00–02: прочитати першу картку й зробити вибір. 02–05: друга картка й пояснення. 05–08: виправити помилку/створити короткий фрагмент головного продукту.

**Хід 1:** “How much time is available for the first draft? Choices: twenty minutes / ten minutes” Учень: “I choose … because …”. Правильно → ще 1 перевірка; помилка → чернетка повертається на доопрацювання. Ключ: **twenty minutes**. Причина: Текст прямо вказує twenty minutes.

**Хід 2:** “What does each station need? Choices: a long list / one clear example” Учень: “I choose … because …”. Правильно → ще 1 перевірка; помилка → чернетка повертається на доопрацювання. Ключ: **one clear example**. Причина: Each station needs one clear example.


**Хід 3, короткий фрагмент:** Write a short display note (45–65 words): choose two different stations, give one accurate contextual example for each, and explain one useful decision. No requirement to cover every station in a long essay. У грі виконати лише одну потрібну частину; повний короткий продукт має свій блок 24–36. Приклад прийнятного повного варіанта, з якого можна взяти одну частину:

Our display links club teamwork with checking media sources. Each station should show one clear example. This will help visitors understand the main point without reading a long list. We have twenty minutes for a draft, so I suggest choosing useful information first and checking its accuracy before sharing the display.

**SEL-дія перед першим ходом 00–02; рефлексія 05–08:** Учень знаходить один доказ у джерелі, відокремлює його від власного припущення й за бажанням формулює нейтральне уточнення до вигаданого героя. Після короткого фрагмента запропонувати необов’язкове запитання: Який спосіб перевірки допоміг у питанні «How much time is available for the first draft?»? У якій іншій ситуації він допоміг би перевірити припущення? Можна поміркувати мовчки/пропустити; відповіді й емоції не оцінюються. Це авторське адаптування для 9 класу з орієнтиром на 4 сили офіційного електронного комплекту; не офіційна вправа «Зерен».

**Стан успіху:** два точні рішення й один фрагмент із доречною формою/жанром. Відкритий фрагмент: потрібна частина жанру/цільова форма, тематично точний зміст, зрозуміле формулювання. Варіанти приймаються, якщо є ці 3 ознаки. Помилка → консультант показує лише релевантне правило/фразу джерела → учень пояснює виправлення й повторює. Запис «після підказки» відокремлюється від першої спроби. Мовний доказ — відповідь+пояснення+фрагмент, не кількість жетонів.

## 2. Незалежна редакторська перевірка —5 хв

**Замість 36–41 A/C**, не додатковий тест після 45 хв. Інший редактор отримує нові наведені нижче стимули. Стартовий стан:2 невирішені редакторські питання; жодної підказки до першої відповіді. Картки й ключі гри 1 закриті.

00–02: перший новий стимул. 02–04: другий новий стимул й одна англійська репліка-пояснення. 04–05: спочатку фіксація мовного доказу, потім необов’язкова коротка рефлексія «Який спосіб перевірки допоміг у питанні «How much time is available for the first draft?»? У якій іншій ситуації він допоміг би перевірити припущення?»; навчальний повтор після фіксації. SEL-відповідь не додає й не знімає бал.

**Новий стимул 1:** “What topic belongs to station1? Choices: checking media sources / club teamwork” Ключ після першої спроби: **club teamwork**. Причина: The numbered display brief supplies this topic.

**Новий стимул 2:** “What topic belongs to station2? Choices: checking media sources / club teamwork” Ключ після першої спроби: **checking media sources**. Причина: Use the final numbered station in the brief.


Учень каже/пише “The source / context shows …” або “This belongs under … because …”. Правильний вибір з поясненням → питання закрито; неправильний вибір → питання залишається відкритим до зворотного зв’язку. **Стан успіху:** обидва правильні рішення й осмислена причина. Фіксація:0–2 точних виборів та окремо є/немає пояснення. Це вузький доказ цілі, не автоматична підсумкова оцінка. Після запису першого результату вчитель дає одну підказку і дозволяє повтор; повтор позначається «з опорою» й не стирає першу самостійну спробу.

## Папір, чат, соло, тихе укриття

Папір: картки за партою, позначки стану ручкою. Чат без камери: приватні вибори й пояснення; це письмовий доказ, не говоріння. Соло: ключ закрито до першої спроби; самоперевірка не видається за перевірку вчителем. Укриття: після дозволу й за умов читання, тільки один короткий письмовий хід на місці **замість** частини мінімуму B/D. Без хорового звуку, руху й особистих історій. Якщо умов немає — перенести. Повні 8+5 хв не додаються до 15 хв укриття. Камера/емоції/життєві обставини не є результатом гри.
