# Ігрові симуляції ·9 клас · урок 121

**Точний фокус:** портфоліо: вибір → корекція → перенесення. Teacher-only: тут є ключі. Усі персонажі/навчальні ситуації вигадані, якщо історичне джерело не зазначене окремо.

## 1. Майстерня рішення — засвоєння,8 хв

**Замість 16–24 A/C**, а не додаткові 8 хв. При підсумковому контролі цю гру використовують як окреме попереднє тренування, не всередині самостійного доказу. Ролі: редактор і консультант; соло — той самий учень спершу редактор, потім читає пояснення. Початковий стан: чернетка 0/2, дозвіл на використання ще не отримано. Мета — ухвалити два предметні рішення саме цієї дати й підготувати фрагмент «портфоліо: вибір → корекція → перенесення».

00–02: прочитати першу картку й зробити вибір. 02–05: друга картка й пояснення. 05–08: виправити помилку/створити короткий фрагмент головного продукту.

**Хід 1:** “What shows transfer of learning? Choices: copying the key without explanation / a new example” Учень: “I choose … because …”. Правильно → ще 1 перевірка; помилка → чернетка повертається на доопрацювання. Ключ: **a new example**. Причина: Перенесення — застосування в новому контексті.

**Хід 2:** “Which record is useful? Choices: original, correction, reason / only a mark” Учень: “I choose … because …”. Правильно → ще 1 перевірка; помилка → чернетка повертається на доопрацювання. Ключ: **original, correction, reason**. Причина: Зберігаємо доказ виправлення.


**Хід 3, короткий фрагмент:** Choose one previous artifact with a genre feature; revise two details, explain each change and write one new example. If no artifact is available, use the two model versions supplied below. У грі виконати лише одну потрібну частину; повний короткий продукт має свій блок 24–36. Приклад прийнятного повного варіанта, з якого можна взяти одну частину:

Correction 1: Skills: organisation — arranged a class book display. CV має рубрику й конкретний доказ навички. Correction 2: Experience: helped organise a three-person class display. Конкретний досвід замість непідтвердженої загальної оцінки. New example: Skills: teamwork — helped two partners prepare a short report.

**SEL-дія перед першим ходом 00–02; рефлексія 05–08:** Перед продуктом «портфоліо: вибір → корекція → перенесення» учень обирає одну потрібну частину, робить короткий план, перевіряє її за вимогою жанру та за бажанням уточнює рішення. Після короткого фрагмента запропонувати необов’язкове запитання: Яка перевірка допомогла тобі працювати з форматом «портфоліо: вибір → корекція → перенесення»? Де ще можна використати такий порядок дій? Можна поміркувати мовчки/пропустити; відповіді й емоції не оцінюються. Це авторське адаптування для 9 класу з орієнтиром на 4 сили офіційного електронного комплекту; не офіційна вправа «Зерен».

**Стан успіху:** два точні рішення й один фрагмент із доречною формою/жанром. Відкритий фрагмент: потрібна частина жанру/цільова форма, тематично точний зміст, зрозуміле формулювання. Варіанти приймаються, якщо є ці 3 ознаки. Помилка → консультант показує лише релевантне правило/фразу джерела → учень пояснює виправлення й повторює. Запис «після підказки» відокремлюється від першої спроби. Мовний доказ — відповідь+пояснення+фрагмент, не кількість жетонів.

## 2. Незалежна редакторська перевірка —5 хв

**Замість 36–41 A/C**, не додатковий тест після 45 хв. Інший редактор отримує нові наведені нижче стимули. Стартовий стан:2 невирішені редакторські питання; жодної підказки до першої відповіді. Картки й ключі гри 1 закриті.

00–02: перший новий стимул. 02–04: другий новий стимул й одна англійська репліка-пояснення. 04–05: спочатку фіксація мовного доказу, потім необов’язкова коротка рефлексія «Яка перевірка допомогла тобі працювати з форматом «портфоліо: вибір → корекція → перенесення»? Де ще можна використати такий порядок дій?»; навчальний повтор після фіксації. SEL-відповідь не додає й не знімає бал.

**Новий стимул 1:** “Move the misplaced line “enjoys reading novels” from Skills to which heading? Choices: Interests / Education” Ключ після першої спроби: **Interests**. Причина: Захоплення → Interests.

**Новий стимул 2:** “Which Skills line supports organisation? Choices: Expert director of an international company. / Arranged books by topic for a class display.” Ключ після першої спроби: **Arranged books by topic for a class display.**. Причина: Конкретне діяння є доказом навички; титул не підтверджено.


Учень каже/пише “The source / context shows …” або “This belongs under … because …”. Правильний вибір з поясненням → питання закрито; неправильний вибір → питання залишається відкритим до зворотного зв’язку. **Стан успіху:** обидва правильні рішення й осмислена причина. Фіксація:0–2 точних виборів та окремо є/немає пояснення. Це вузький доказ цілі, не автоматична підсумкова оцінка. Після запису першого результату вчитель дає одну підказку і дозволяє повтор; повтор позначається «з опорою» й не стирає першу самостійну спробу.

## Папір, чат, соло, тихе укриття

Папір: картки за партою, позначки стану ручкою. Чат без камери: приватні вибори й пояснення; це письмовий доказ, не говоріння. Соло: ключ закрито до першої спроби; самоперевірка не видається за перевірку вчителем. Укриття: після дозволу й за умов читання, тільки один короткий письмовий хід на місці **замість** частини мінімуму B/D. Без хорового звуку, руху й особистих історій. Якщо умов немає — перенести. Повні 8+5 хв не додаються до 15 хв укриття. Камера/емоції/життєві обставини не є результатом гри.
