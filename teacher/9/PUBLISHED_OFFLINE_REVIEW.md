# Опублікований сайт: перевірка offline-місій 9 класу

Перевірено 18 жовтня 2026 року, завершення близько 20:15 UTC. У перевіреній вибірці дефектів не виявлено. Це фактичний браузерний тест опублікованого HTTPS-сайту, а не висновок із локального коду.

## Сторінки та середовище

- [Gerund](https://vovche.github.io/esl-lessons/9/gerund/): ситуація `g9-023`, яка не є першою у списку.
- [Future forms v2](https://vovche.github.io/esl-lessons/9/future-forms-v2/): ситуація `g9-009`, запуск через кнопку «Ігрові місії» повноекранного уроку.
- Chromium / Playwright, два окремі свіжі contexts без попередніх даних сайту; viewport 390 × 844, touch/mobile, reduced motion.
- Дані й варіанти відповідей отримано HTTP-запитом до [опублікованого JSON](https://vovche.github.io/esl-lessons/9/simulations.json). Локальний JSON не використовувався.
- Мережеві ресурси цього origin і service worker завантажувалися з реального GitHub Pages. Сторонні embed-ресурси заблоковано, тому перевірка не оцінює стороннє відео.
- Перед відключенням мережі дочекалися повідомлення «Місії готові до роботи без інтернету й перезавантаження». Зареєстровано справжній HTTPS service worker `https://vovche.github.io/esl-lessons/simulations-sw.js`, scope `https://vovche.github.io/esl-lessons/`.

## Межі

Фактично пройдено дві ситуації, чотири місії та вісім основних кроків; це не ручна перевірка всіх 121 ситуації. Відсутність мережі змодельовано `context.setOffline(true)` у Chromium. Не перевірялися фізичне знеструмлення пристрою, iOS/Safari, Firefox, приватний режим, очищення/витіснення cache, закриття всього браузера або offline-перше відвідування без попередньої підготовки. Для готовності потрібні перше online-завантаження та збережені дані цього пристрою. Viewport 320 px і landscape у цій окремій published-перевірці не тестувалися. Зміни до runtime чи навчального контенту за результатами цього тесту не були потрібні.
