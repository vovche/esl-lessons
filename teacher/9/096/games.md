# Ігрові симуляції ·9 клас · урок 096

**Точний фокус:** Second Conditional. Teacher-only: тут є ключі. Усі персонажі/навчальні ситуації вигадані, якщо історичне джерело не зазначене окремо.

## 1. Майстерня рішення — засвоєння,8 хв

**Замість 16–24 A/C**, а не додаткові 8 хв. При підсумковому контролі цю гру використовують як окреме попереднє тренування, не всередині самостійного доказу. Ролі: редактор і консультант; соло — той самий учень спершу редактор, потім читає пояснення. Початковий стан: чернетка 0/2, дозвіл на використання ще не отримано. Мета — ухвалити два предметні рішення саме цієї дати й підготувати фрагмент «Second Conditional».

00–02: прочитати першу картку й зробити вибір. 02–05: друга картка й пояснення. 05–08: виправити помилку/створити короткий фрагмент головного продукту.

**Хід 1:** “Imagine being the head teacher: If I managed the school, I ___ refill stations. Choices: would add / will added” Учень: “I choose … because …”. Правильно → ще 1 перевірка; помилка → чернетка повертається на доопрацювання. Ключ: **would add**. Причина: Уявна ситуація: would + verb.

**Хід 2:** “We do not have a garden. If we ___ a garden, we would grow vegetables. Choices: have / had” Учень: “I choose … because …”. Правильно → ще 1 перевірка; помилка → чернетка повертається на доопрацювання. Ключ: **had**. Причина: If + Past Simple.


**Хід 3, короткий фрагмент:** Complete the contextual language items. Then write one new two-clause example using the target form and explain its meaning in Ukrainian or English. У грі виконати лише одну потрібну частину; повний короткий продукт має свій блок 24–36. Приклад прийнятного повного варіанта, з якого можна взяти одну частину:

If I had more space, I would start a small garden. Explanation: If + Past Simple, would + verb — уявна/малоймовірна теперішня або майбутня ситуація. Past форма тут не позначає завершеної минулої події.

**SEL-дія перед першим ходом 00–02; рефлексія 05–08:** Перш ніж обрати відповідь для «Second Conditional», учень за бажанням робить коротку паузу, знаходить часову/смислову ознаку і перевіряє своє рішення. У перевірному раунді пояснення дається після фіксації першої спроби. Після короткого фрагмента запропонувати необов’язкове запитання: Яка ознака допомогла обрати рішення у завданні «Second Conditional»? Де ще стане в пригоді пауза перед вибором? Можна поміркувати мовчки/пропустити; відповіді й емоції не оцінюються. Це авторське адаптування для 9 класу з орієнтиром на 4 сили офіційного електронного комплекту; не офіційна вправа «Зерен».

**Стан успіху:** два точні рішення й один фрагмент із доречною формою/жанром. Відкритий фрагмент: потрібна частина жанру/цільова форма, тематично точний зміст, зрозуміле формулювання. Варіанти приймаються, якщо є ці 3 ознаки. Помилка → консультант показує лише релевантне правило/фразу джерела → учень пояснює виправлення й повторює. Запис «після підказки» відокремлюється від першої спроби. Мовний доказ — відповідь+пояснення+фрагмент, не кількість жетонів.

## 2. Незалежна редакторська перевірка —5 хв

**Замість 36–41 A/C**, не додатковий тест після 45 хв. Інший редактор отримує нові наведені нижче стимули. Стартовий стан:2 невирішені редакторські питання; жодної підказки до першої відповіді. Картки й ключі гри 1 закриті.

00–02: перший новий стимул. 02–04: другий новий стимул й одна англійська репліка-пояснення. 04–05: спочатку фіксація мовного доказу, потім необов’язкова коротка рефлексія «Яка ознака допомогла обрати рішення у завданні «Second Conditional»? Де ще стане в пригоді пауза перед вибором?»; навчальний повтор після фіксації. SEL-відповідь не додає й не знімає бал.

**Новий стимул 1:** “We have no workshop now. If we had one, we ___ broken items there. Choices: will repaired / would repair” Ключ після першої спроби: **would repair**. Причина: Second, уявна теперішня ситуація.

**Новий стимул 2:** “If Robin ___ more time now, they would volunteer. Choices: had / has” Ключ після першої спроби: **had**. Причина: If + Past Simple.


Учень каже/пише “The source / context shows …” або “This belongs under … because …”. Правильний вибір з поясненням → питання закрито; неправильний вибір → питання залишається відкритим до зворотного зв’язку. **Стан успіху:** обидва правильні рішення й осмислена причина. Фіксація:0–2 точних виборів та окремо є/немає пояснення. Це вузький доказ цілі, не автоматична підсумкова оцінка. Після запису першого результату вчитель дає одну підказку і дозволяє повтор; повтор позначається «з опорою» й не стирає першу самостійну спробу.

## Папір, чат, соло, тихе укриття

Папір: картки за партою, позначки стану ручкою. Чат без камери: приватні вибори й пояснення; це письмовий доказ, не говоріння. Соло: ключ закрито до першої спроби; самоперевірка не видається за перевірку вчителем. Укриття: після дозволу й за умов читання, тільки один короткий письмовий хід на місці **замість** частини мінімуму B/D. Без хорового звуку, руху й особистих історій. Якщо умов немає — перенести. Повні 8+5 хв не додаються до 15 хв укриття. Камера/емоції/життєві обставини не є результатом гри.
