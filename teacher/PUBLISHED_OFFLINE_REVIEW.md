# Офлайн-перевірка опублікованого сайту

18.10.2026. Адреса: https://vovche.github.io/esl-lessons/. Перевірено опублікований коміт `8a3205ae270ed50630b9c125d716d9a23134f676` у трьох паралельних потоках: [6 клас](6/PUBLISHED_OFFLINE_REVIEW.md), [7 клас](7/PUBLISHED_OFFLINE_REVIEW.md), [9 клас](9/PUBLISHED_OFFLINE_REVIEW.md).

## Спільна регресія

`tests/playtest_offline_simulations.cjs` пройшов на реальному HTTPS-сайті для g6-002, g7-037 і g9-023 у свіжих Chromium-контекстах із viewport 390×844 та touch. HTML, JS, CSS і JSON отримано з опублікованого сайту; локальна копія даних не використовувалася. Сторонні origins відеовставок блокувалися для ізоляції ігор; власні запити сайту не підмінялися. Мережу вимикали через `context.setOffline(true)`.

У кожному класі перевірено: перше відкриття, готовність кешу, непершу календарну ситуацію, неправильну відповідь/підказку/паузу, reload без мережі, завершення з результатом 1/2, чернетку, повторний reload, незмінність першого вибору в перевірній грі, нову вкладку офлайн та повернення до повного уроку після відновлення мережі. Натискання кнопки повернення без зв’язку дає зрозуміле повідомлення й не закриває гру. Помилок JavaScript власного інтерфейсу немає.

[Машинний підсумок](published-offline-results.json). HTTP 200, MIME та SHA256 опублікованих worker, оболонки, обох JS і трьох JSON перевірено окремо: файли відповідають локальній запушеній версії.

## Результат трьох потоків

Нових функціональних дефектів у перевірених сценаріях не виявлено; змінювати опублікований runtime не знадобилося. Окремі потоки додатково перевірили 6 клас на 320 і 390 px, g7-065 у перевірному режимі та g9-009 у повноекранному уроці future-forms-v2.

## Зміни перевірки

Регресійний тест тепер читає JSON із того самого сервера, який тестує, замість локального репозиторію. Додано явну перевірку кнопки повернення при відсутній мережі. Це дозволяє відтворювати перевірку розгорнутої версії командою:

```sh
SIM_BASE_URL=https://vovche.github.io/esl-lessons/ node tests/playtest_offline_simulations.cjs
```

Потрібні встановлені Playwright і Chromium. Службові звіти та результати залишаються в `teacher/` і виключаються з публічного артефакту.

## Межі

Свіже перше відкриття без інтернету й без попереднього кешу неможливе. Перед перервою слід відкрити ігри онлайн та дочекатися повідомлення готовності. Офлайн доступні ігри, а не відео чи весь урок. Перевірка виконана в Chromium з емуляцією мобільного viewport; реальні телефони, Safari, приватний режим і очищення даних не тестувалися.
