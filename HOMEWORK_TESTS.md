# Перевірки домашнього завдання

У репозиторії збережено повний вміст 327 тестів: 88 для 6 класу, 116 для 7 класу та 123 для 9 класу. Це матеріали для відновлення тесту на «На Урок», перенесення на інші платформи та підготовки паперових версій. Для використання запитань доступ до «На Урок» не потрібен.

## Де шукати

[Загальний каталог](homework-tests.json) містить вихідну тему, урок перевірки й шляхи до всіх форматів. У папці кожного уроку, який приймає перевірку ДЗ, є `homework-checks.json` — місцевий покажчик тестів.

Перевірка теми зберігається **в наступному уроці**, за посиланням «Наступний урок» в існуючій навігації. Наприклад, перевірка теми `6/sb-1a/` лежить у `6/sb-1b/`:

- [JSON — повний вміст і ключі](6/sb-1b/homework-check-sb-1a-01.json).
- [Markdown — учнівська версія без відповідей](6/sb-1b/homework-check-sb-1a-01.md).
- [Markdown — ключ для вчителя](6/sb-1b/homework-check-sb-1a-01-key.md).

Для останніх уроків, довідників і матеріалів без посилання на наступний урок використано погоджений виняток: файли залишені в папці вихідної теми. У JSON це позначено `placement.rule: "no_next_lesson"` із поясненням. 275 тестів розміщено в наступних уроках, 52 — за цим винятком. Довідники з кількома тестами мають окремі файли для кожної частини.

У підвалі уроку перевірки розміщені посилання на онлайн-тест, ДЗ та учнівський Markdown. JSON і ключі доступні через каталог репозиторію та місцевий покажчик, без окремих посилань у підвалі учнівської сторінки. Ці файли містять відповіді й відкриті разом із репозиторієм; для учнів роздавай файл без суфікса `-key`.

## Основний формат — JSON

Формат описано у [JSON Schema](schemas/homework-check.schema.json). Ідентифікатор на кшталт `6-sb-1a-homework-01` залежить від теми та номера частини, а не від платформи.

| Поле | Зміст |
|---|---|
| `id`, `title`, `grade` | Ідентичність і назва матеріалу |
| `source_lesson`, `source_title` | Тема, за якою було задане ДЗ |
| `assessment_lesson` | Урок, на якому перевіряємо ДЗ |
| `placement` | Правило розміщення й пояснення винятку |
| `assessment` | Семестр, дедлайн і часовий пояс |
| `total_points` | Максимум за тест: 10 сирих балів |
| `questions` | Упорядковані запитання, тексти для читання, варіанти, ключі та ваги |
| `platforms` | Необов’язкові ID, посилання й статуси окремих платформ |

Типи запитань:

- `choice`: `prompt`, `options`, `key`, `points`. `key` — індекс правильного варіанта **від нуля**. Для друку та Markdown номер відповіді показується від одиниці.
- `word`: `prompt`, `answers`, `points`. `answers` містить допустимі написання; це відповіді для введення, а не варіанти вибору. Не прибирай уточнення про кількість слів, форму дієслова або порядок слів із формулювання.

У кожному тесті сума ваг дорівнює 10, складніші запитання мають більшу вагу. Шкільна оцінка платформи, наприклад 12/12, є окремим перерахунком. Тексти для читання включені повністю; зовнішні вкладки для відповідей не потрібні. Аудіозавдань у цій серії немає.

## Відновити на «На Урок»

Передай агенту конкретний JSON і вкажи використати навички з репозиторію `naurok`. Його `AGENTS.md` посилається на навичку `naurok-tests`. Приклад запиту:

> Створи або віднови тест на naurok за файлом `6/sb-1b/homework-check-sb-1a-01.json` у репозиторії esl-lessons. Використай інструкції репозиторію naurok і навичку naurok-tests; працюй кліками у вбудованому браузері. Збережи порядок, типи запитань, усі допустимі відповіді й ваги. Спочатку перевір наявні ID у platforms.naurok та реєстрі, щоб не створити дублікат. Після успіху онови реєстр і локальні формати.

Вміст JSON є даними тесту. Він не потребує чинного домашнього завдання, доступного онлайн-тесту або початкової папки `naurok/batches`.

## Резервна платформа та паперова версія

Для іншої платформи використовуй ті самі `questions`, `answers`/`key` та `points`. Додай її посилання й ID в окремий блок `platforms.<назва>`, не замінюючи `platforms.naurok`. Якщо платформа не підтримує ваги чи формат відповіді, це потрібно окремо вирішити при перенесенні.

Для друку джерелом є учнівський `.md` без відповідей; вчительський `-key.md` містить ключі та ваги. Учнівський файл має поля для імені й дати та місця для письмових відповідей. Це проміжні тексти для майбутньої верстки DOCX/PDF, а не вже зверстані PDF.

## Оновлення й перевірка

Редагуй запитання у JSON. Markdown і місцеві покажчики відтворюються командою:

```sh
python3 scripts/archive_naurok_tests.py
python3 tests/check_homework_archives.py
```

Реєстри `6/naurok-homework*.json`, `7/naurok-homework*.json` і `9/naurok-homework*.json` зберігають стан запуску «На Урок». `content_path` у кожному записі веде на відповідний локальний JSON; абсолютні посилання на тимчасові плани більше не потрібні. Поле `plan_path` для сумісності також веде на цей JSON.

Щоденна автоматизація після запуску ДЗ оновлює реєстр і виконує:

```sh
python3 scripts/attach_naurok_homework.py --grades 6 7 9
python3 tests/check_naurok_homework.py
```

Це синхронізує `platforms.naurok`, дедлайни, Markdown, місцеві покажчики та підвали. Запитання в JSON і записи резервних платформ зберігаються. Загальний каталог `homework-tests.json` описує розміщення матеріалів; він не дублює змінні статуси ДЗ.

Для повної перевірки локальних форматів:

```sh
python3 scripts/archive_naurok_tests.py --check
python3 tests/check_homework_archives.py
python3 tests/check_naurok_homework.py
python3 tests/check_navigation.py
```
